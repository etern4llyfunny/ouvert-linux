## Блокеры

### B1. Обновления своих пакетов — ЗАКРЫТ 11.11.2026
Закрыт: Патч 80, beta-22, ВМ t54 (и ручной прогон t53). Поднят публичный онлайн-репо etern4llyfunny/ouvert-repo (релиз x86_64: linux-ouvert*, ouvert-branding, ouvert-keyring). На свежей установке t54 [ouvert] остаётся в pacman.conf цели, в `pacman -Qm` только 6 AUR-пересборок (linux-ouvert* и ouvert-branding отсутствуют), обновления приезжают через `pacman -Syu`.
Сейчас: config_gen.py вырезает [ouvert] из pacman.conf цели (стр. 268–280) —
намеренно, чтобы paru обновлял AUR-пересборки из AUR.
Замер t47/beta-18 (05.11): `pacman -Qm` → linux-ouvert 7.2.8-1 и
ouvert-branding 1.0-7 — сироты: ни в одном репо, ни в AUR, обновлений нет никогда.
Риск: paru ищет сирот в AUR по имени. Пакет `linux-ouvert` или `ouvert-branding`,
залитый в AUR кем угодно с версией выше, приедет на все установки при `paru -Syu`.
Направление: онлайн-репо [ouvert] только со СВОИМИ пакетами (linux-ouvert*,
ouvert-branding, ouvert-keyring), остаётся в pacman.conf цели. AUR-пересборки
(waterfox-bin, paru, protonup-qt, python-steam, python-inputs,
python-gevent-eventemitter) — только в локальном репо ISO, как сейчас.
Критерий: на свежей установке `pacman -Qm` не содержит linux-ouvert* и
ouvert-branding; выложенный ouvert-branding с pkgrel+1 приезжает через
`sudo pacman -Syu`.

### B2. Подпись репозитория — ЗАКРЫТ 11.11.2026
Закрыт: Патч 80, beta-22, ВМ t54 (и t53). Создан ключ подписи ed25519 и пакет ouvert-keyring 20261111-1 (ставится установщиком, `pacman-key --populate ouvert`). В pacman.conf цели `[ouvert]` с `SigLevel = Required`; неподписанную базу pacman отверг («не найдена необходимая подпись» на t53), подписанные база и пакеты проходят проверку ключей и `pacman -Syu`.
Сейчас: SigLevel = Optional TrustAll.
Критерий: [ouvert] с SigLevel = Required; ключ — пакет ouvert-keyring,
ставится установщиком; `pacman -Syu` проходит; пакет с битой подписью
pacman отвергает.

### B3. Обновление ядра linux-ouvert — ЗАКРЫТ 20.11.2026
Закрыт: `pkgbuilds/linux-ouvert/ouvert_kernel_prep.py` + `UPDATE.md`, хост и ВМ ouvert-t54. Ядро `linux-ouvert 7.3.4-1` собрано из upstream CachyOS (13.11), подписано, проверено на хосте (15.11, DKMS nvidia 620, 0 failed units) и выложено в релиз `x86_64` ouvert-repo. На установленной ВМ t54 (7.2.8-1 -> 7.3.4-1) прошёл `sudo pacman -Syu` (157,7 МиБ за 41 с, 3,81 МиБ/с, проверка ключей 113/113 ок, initramfs собран); после ребута `uname -r` = `7.3.4-1-ouvert`, `kernel.sched_bore = 1`, `0 loaded units listed`.
Сейчас: 7.2.8, не обновлялось с конца сентября.
Критерий: записанная процедура (скрипт): сборка новой версии → подпись →
выкладка в репо; установленная ВМ обновилась через `pacman -Syu` и
загрузилась на новом ядре (`uname -r`).

### B4. Установка на реальном железе — ЗАКРЫТ 20.11.2026
Закрыт (3 реальные машины — AMD/iGPU, Nvidia, ноутбук с Wi-Fi и тачпадом):
- Ноутбук Lunnen Outer 16 Pro (AMD Ryzen 7 7840HS + Radeon 780M `amdgpu`, Intel Wi-Fi 6E AX210 `iwlwifi`, тачпад) | GNOME 51.1 (Wayland) | beta-22 -> `pacman -Syu` (`7.3.4-1-ouvert`) | ручной дуалбут с Windows (`btrfs`), GRUB подхватил Windows, `kernel.sched_bore = 1`, `0 loaded units` — ок.
- ПК друга (Intel + Nvidia) | полная установка, загрузка, вход в окружение — ок.
- ПК (AMD) | полная установка, загрузка, вход в окружение — ок.
Критерий: полная установка + загрузка + вход в окружение минимум на 3 машинах:
Intel или AMD графика, Nvidia, ноутбук (Wi-Fi, тачпад).
По каждой — строка: машина, окружение, бета, итог.

### B5. BIOS / legacy-загрузка — ЗАКРЫТ 09.11.2026
Закрыт: beta-19, ВМ t50 (SeaBIOS, virt-install без --boot uefi, в XML нет loader):
live через syslinux, установщик «BIOS (Legacy)», i3 без ошибок, GRUB с диска,
установленная: /sys/firmware/efi нет, vda PTTYPE dos, vda1 vfat /boot, vda2 btrfs.
Критерий: ВМ с SeaBIOS — live грузится, установка проходит, установленная
система грузится. Либо решение «только UEFI»: тогда live и установщик
внятно говорят об этом на BIOS-машине.

### B6. Bug 34(д) — повтор после оборванной установки  — ЗАКРЫТ 09.11.2026
Закрыт: beta-20, t52. Сеть ВМ оборвана на синхронизации баз (domif-setlink down), установщик упал за минуту, /mnt и сабволюмы остались смонтированы; повтор в той же сессии (ouvert из tty2) на тот же диск — «Готово»: archinstall сам размонтирует /mnt. После перезагрузки точек монтирования нет вовсе.
Критерий: обрыв на pacstrap → повторная установка на тот же диск проходит
без «Удалять нельзя: примонтирован» (после перезагрузки и, если такой путь
есть, без неё).

### B7. Bug 57 — два монитора  — ЗАКРЫТ 09.11.2026
Закрыт: beta-20 с флешки, десктоп с двумя мониторами. Шаги 1–5, 9, 10 сняты на фото, 6–8 проверены на глаз: окно на одном мониторе, по центру, не растянуто; диалог ошибки внутри панели; заставка на оба монитора. Шаг 11 без установки не открыть — не проверялся.
Критерий: live на машине с двумя мониторами, все 11 шагов: окно видно
целиком, не растянуто, кнопки доступны.
